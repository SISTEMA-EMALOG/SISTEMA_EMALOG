Como funciona o sistema de backup

  • Backup automático diário às 02h00 UTC — criado automaticamente
  • Cada backup gera dois arquivos: .json (dados legíveis) e .db (cópia fiel do banco)
  • Os últimos 30 backups são mantidos automaticamente — os mais antigos são removidos
  • Senhas são mascaradas no arquivo JSON por segurança
  • Faça download regular do arquivo .db para armazenar fora do servidor
